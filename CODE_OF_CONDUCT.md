# Code of Conduct

Tinsel follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, and keep discussions about the work. Harassment of any kind is not tolerated.

To report a problem, open an issue marked **conduct** or contact the maintainer through their GitHub profile. Reports are handled privately.
